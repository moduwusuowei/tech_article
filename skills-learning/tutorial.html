从 0 到 1 实现天气查询 Skill

手把手教你创建一个实用的生活化 Skill

📋 项目介绍

我们将创建一个「上海实时天气」Skill，功能包括：

  • 查询上海当前的温度、湿度、天气状况
  • 显示穿衣指数、紫外线等级等生活建议
  • 支持语音播报结果
🌰 使用效果

用户说："上海现在天气怎么样？"

Skill 返回：

📍 上海 | ☀️ 晴 | 🌡️ 28°C | 💧 湿度 65%

👕 穿衣建议：短袖即可，注意防晒

☀️ 紫外线：中等，外出建议戴帽子

🔧 技术选型

在开始之前，我们需要确定技术方案：

  • 天气数据源：OpenWeatherMap / 和风天气 API
  • Skill 框架：OMC Skill 格式
  • 触发方式：关键词 + 位置名
  • 输出格式：结构化文本 + 语音播报
💡 API 选择

推荐使用和风天气 API（qweather.com），国内访问稳定，免费额度够用。

Step 1: 创建 Skill 目录结构

首先创建 Skill 的文件夹和基础文件：

mkdir -p ~/.claude/skills/omc-learned/weather-shanghai

目录结构：

weather-shanghai/ ├── SKILL.md # Skill 定义文件 └── src/ ├── api.js # 天气 API 调用 ├── format.js # 格式化输出 └── tts.js # 语音播报
💡 命名规范

Skill 名称使用小写 + 连字符格式，如：weather-shanghai、stock-query

Step 2: 编写 SKILL.md

SKILL.md 是 Skill 的核心定义文件，包含元数据和执行逻辑：

---
name: weather-shanghai
description: 查询上海实时天气和生活建议
triggers:
  - "上海天气"
  - "上海 现在"
  - "上海 temperature"
argument-hint: ""
level: 2
---

# 上海天气查询 Skill

## Purpose
查询上海实时天气，返回温度、湿度、天气状况，
并给出穿衣、防晒等生活建议。

## When to Activate
- 用户提到"上海天气"
- 用户询问"上海现在多少度"
- 用户说"上海热不热"

## Workflow

### 1. 调用天气 API

\`\`\`javascript
const weather = await callWeatherAPI('上海');
// 返回数据结构：{ temp, humidity, condition, ... }
\`\`\`

### 2. 生成生活建议

根据温度和天气状况生成建议：
- 🌡️ < 15°C → 建议穿外套
- 🌡️ 15-25°C → 建议穿长袖
- 🌡️ > 25°C → 建议穿短袖

### 3. 格式化输出

输出格式：
📍 上海 | 🌡️ {temp}°C | {condition}
{生活建议}

## Examples

```
user: 上海天气怎么样
assistant: 📍 上海 | ☀️ 晴 | 🌡️ 28°C | 💧 65%
👕 穿衣：短袖即可，注意防晒
☀️ 紫外线：中等，建议戴帽子
```

## Notes
- 使用和风天气 API
- 缓存结果 10 分钟避免重复请求
- 语音播报使用 Web Speech API

Step 3: 实现天气 API 调用

创建 src/api.js 处理 API 调用：

/**
 * 获取上海实时天气
 * API: 和风天气
 * Doc: https://dev.qweather.com/
 */

const CACHE_KEY = 'weather_shanghai';
const CACHE_TTL = 10 * 60 * 1000; // 10分钟

async function getWeather() {
  // 检查缓存
  const cached = getCache(CACHE_KEY);
  if (cached && !isExpired(cached.timestamp, CACHE_TTL)) {
    return cached.data;
  }

  // 调用 API
  const response = await fetch(
    \`https://dev.qweather.com/v7/weather/now?location=101020100&key=YOUR_KEY\`
  );
  const data = await response.json();

  // 格式化数据
  const result = {
    temp: data.now.temp,
    feelsLike: data.now.feelsLike,
    humidity: data.now.humidity,
    condition: data.now.text,
    wind: data.now.windDir + data.now.windScale,
    updateTime: data.now.updateTime
  };

  // 写入缓存
  setCache(CACHE_KEY, result);

  return result;
}

module.exports = { getWeather };
⚠️ 注意

需要替换 YOUR_KEY 为你的和风天气 API Key，免费注册即可获得。

Step 4: 实现生活建议生成

创建 src/format.js 生成格式化输出和生活建议：

/**
 * 生成生活建议
 */

function generateSuggestions(weather) {
  const suggestions = [];

  // 穿衣建议
  const temp = parseInt(weather.temp);
  if (temp < 15) {
    suggestions.push('🧥 穿衣：建议穿外套，早晚温差大');
  } else if (temp < 25) {
    suggestions.push('👕 穿衣：适合穿长袖或薄外套');
  } else {
    suggestions.push('🩳 穿衣：建议穿短袖，注意防晒');
  }

  // 紫外线建议
  if (weather.condition.includes('晴')) {
    suggestions.push('☀️ 紫外线：较强，建议戴帽子或太阳镜');
  } else if (weather.condition.includes('阴')) {
    suggestions.push('🌤️ 紫外线：较弱，外出无需特别注意');
  }

  // 运动建议
  if (temp > 30 || temp < 5) {
    suggestions.push('🏃 运动：室内运动更适宜');
  } else {
    suggestions.push('🏃 运动：天气适宜户外运动');
  }

  return suggestions;
}

// 格式化输出
function formatOutput(weather) {
  const suggestions = generateSuggestions(weather);

  const emoji = {
    '晴': '☀️',
    '阴': '☁️',
    '多云': '⛅',
    '雨': '🌧️',
    '雪': '❄️',
    '雾': '🌫️'
  };

  const condition = weather.condition;
  const emojiStr = emoji[condition] || '🌤️';

  return [
    \`📍 上海 | \${emojiStr} \${condition} | 🌡️ \${weather.temp}°C | 💧 \${weather.humidity}%\`,
    '',
    ...suggestions,
    '',
    \`🕐 更新于 \${formatTime(weather.updateTime)}\`
  ].join('\n');
}

module.exports = { generateSuggestions, formatOutput };

async function getWeather(city) {

  const response = await fetch(
    \`https://dev.qweather.com/v7/weather/now?location=\${locationId}&key=YOUR_KEY\`
  );
  return response.json();
}
