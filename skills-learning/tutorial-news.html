# 新闻聚合 Skill

## When to Activate
- 用户说"新闻"、"今日热点"
- 用户说"科技新闻"、"财经新闻"
- 用户询问特定话题的最新消息

## Workflow

### 1. 确定新闻分类
支持分类：
- 科技 (tech)
- 财经 (finance)
- 体育 (sports)
- 娱乐 (entertainment)
- 社会 (society)
- 默认显示全部

### 2. 获取新闻
\`\`\`javascript
const news = await fetchNews({ category, limit: 10 });
// 返回新闻列表
\`\`\`

### 3. 格式化输出
显示标题、来源、时间，按时间排序

### 4. 收藏功能（可选）
用户说"收藏"时保存到本地

## Examples

## Notes
- 使用 RSS 或新闻 API 获取数据
- 缓存新闻列表 30 分钟
- 支持关键词搜索

📡 使用 RSS 获取新闻

RSS 是获取新闻最简单的方式，无需 API Key：

/**
 * RSS 新闻源配置
 */
const RSS_SOURCES = {
  tech: [
    'https://36kr.com/feed',
    'https://www.ifairer.com/feed/',
    'https://feeds.appinn.com/appinn/'
  ],
  finance: [
    'https://36kr.com/feed/search/%E9%87%91%E8%9E%8D',
    'https://wallstreetcn.com/rss'
  ],
  default: [
    'https://www.zhihu.com/rss'
  ]
};

/**
 * 获取新闻列表
 */
async function fetchNews({ category = 'default', limit = 10 } = {}) {
  const sources = RSS_SOURCES[category] || RSS_SOURCES.default;
  const allNews = [];

  for (const url of sources) {
    try {
      const feed = await parseRSS(url);
      allNews.push(...feed.items.slice(0, limit));
    } catch (e) {
      console.error(\`Failed to fetch \${url}\`, e);
    }
  }

  // 按时间排序
  allNews.sort((a, b) => new Date(b.pubDate) - new Date(a.pubDate));

  return allNews.slice(0, limit).map(item => ({
    title: item.title,
    link: item.link,
    description: stripHtml(item.contentSnippet || item.content),
    source: extractSource(item.link),
    pubDate: item.pubDate
  }));
}

/**
 * 格式化新闻列表
 */
function formatNewsList(news) {
  return news.map((item, i) => {
    const timeAgo = getTimeAgo(new Date(item.pubDate));
    return [
      \`\${i + 1}. \${item.title}\`,
      \`   📰 \${item.source} · \${timeAgo}\`
    ].join('\n');
  }).join('\n\n');
}

⭐ 收藏功能

/**
 * 收藏新闻
 */
async function bookmarkNews(index) {
  const news = await getCachedNews();
  const item = news[index];

  if (!item) throw new Error('新闻不存在');

  const bookmarks = await getBookmarks();
  bookmarks.unshift({
    ...item,
    bookmarkedAt: Date.now()
  });

  await saveBookmarks(bookmarks);
  return \`✅ 已收藏「\${item.title}」\`;
}

/**
 * 查看收藏列表
 */
async function showBookmarks() {
  const bookmarks = await getBookmarks();

  if (bookmarks.length === 0) {
    return '📚 还没有收藏的新闻';
  }

  return [
    '📚 我的收藏',
    ...bookmarks.map((item, i) =>
      \`\${i + 1}. \${item.title}\n   \${item.source} · 收藏于 \${formatDate(item.bookmarkedAt)}\`
    )
  ].join('\n\n');
}
