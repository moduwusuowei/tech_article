股票查询 Skill

从 0 到 1 实现股票价格查询与提醒

📋 项目目标

创建一个股票查询 Skill，功能包括：

  • 查询股票实时价格、涨跌幅、成交量
  • 支持按股票代码或名称查询
  • 显示当日最高/最低价
  • 价格达到阈值时发送提醒
🌰 使用效果

用户说："帮我查一下贵州茅台的股价"

Skill 返回：

🏢 贵州茅台 (600519)

💰 现价：1688.00 元

📈 涨跌：+28.50 (+1.72%)

📊 最高：1695.00 | 最低：1658.00

🔔 成交量：3.2万手

🔧 技术选型

  • 数据源：东方财富 API / 新浪财经 API
  • 股票代码：上交所 600xxx，深交所 000xxx
  • 缓存策略：价格数据缓存 5 分钟
  • 提醒机制：本地存储阈值，达到时通知
💡 免费 API 推荐

使用新浪财经的无认证接口，无需 API Key，但有频率限制。

# 股票查询 Skill

## When to Activate
- 用户提到"查股票"、"股价"
- 用户询问特定股票的价格
- 用户说"帮我看看xxx的走势"

## Workflow

### 1. 解析股票代码
支持多种输入格式：
- 股票代码：600519
- 股票名称：贵州茅台
- 拼音缩写：GZMT

### 2. 调用股票 API
\`\`\`javascript
const quote = await fetchStockQuote(code);
// 返回：{ price, change, pct, high, low, volume, ... }
\`\`\`

### 3. 格式化输出
显示价格、涨跌幅、成交量等关键数据

### 4. 价格提醒（可选）
如果用户设置了提醒阈值，检查是否触发

## Examples

```
user: 帮我查一下贵州茅台
assistant: 🏢 贵州茅台 (600519)
💰 现价：1688.00 元 | 📈 +1.72%
📊 成交：3.2万手 | 市值：2.12万亿
```

## Notes
- 使用新浪财经实时数据
- 缓存5分钟避免频繁请求
- 支持上交所/深交所股票

💻 核心代码实现

股票 API 调用 (src/stock.js)：

/**
 * 获取股票实时行情
 * 使用新浪财经接口
 */

const STOCK_NAME_MAP = {
  '贵州茅台': '600519',
  '腾讯': '00700',
  '阿里巴巴': '09988',
  '特斯拉': 'TSLA',
  // 可扩展更多映射
};

async function getStockQuote(input) {
  // 解析股票代码
  let code = input;
  if (!/^\d+$/.test(input)) {
    code = STOCK_NAME_MAP[input] || await searchStock(input);
  }

  // 调用新浪财经 API
  const url = \`https://hq.sinajs.cn/list=\${code}\`;
  const response = await fetch(url, {
    headers: { 'Referer': 'https://finance.sina.com.cn' }
  });
  const text = await response.text();

  // 解析返回数据
  // 格式："name,open,close,current,high,low,..."
  const data = text.split('="')[1].split('"')[0].split(',');

  return {
    name: data[0],
    open: parseFloat(data[1]),
    close: parseFloat(data[2]),
    current: parseFloat(data[3]),
    high: parseFloat(data[4]),
    low: parseFloat(data[5]),
    volume: formatVolume(data[8]),
    time: data[31]
  };
}

function formatOutput(quote) {
  const change = quote.current - quote.close;
  const pct = (change / quote.close * 100).toFixed(2);
  const arrow = change >= 0 ? '📈' : '📉';

  return [
    \`🏢 \${quote.name}\`,
    \`💰 现价：\${quote.current.toFixed(2)} 元\`,
    \`\${arrow} 涨跌：\${change >= 0 ? '+' : ''}\${change.toFixed(2)} (\${pct}%)\`,
    \`📊 最高：\${quote.high} | 最低：\${quote.low}\`,
    \`🔔 成交量：\${quote.volume}`
  ].join('\n');
}

module.exports = { getStockQuote, formatOutput };

🔔 价格提醒功能

添加设置价格提醒的功能：

/**
 * 设置价格提醒
 */
function setAlert(stockCode, targetPrice, type) {
  const alerts = JSON.parse(localStorage.getItem('stockAlerts') || '{}');
  alerts[stockCode] = { targetPrice, type, enabled: true };
  localStorage.setItem('stockAlerts', JSON.stringify(alerts));
}

/**
 * 检查是否触发提醒
 */
async function checkAlerts(quote) {
  const alerts = JSON.parse(localStorage.getItem('stockAlerts') || '{}');
  const alert = alerts[quote.code];

  if (!alert || !alert.enabled) return;

  if (alert.type === 'above' && quote.current >= alert.targetPrice) {
    return \`📢 【提醒】\${quote.name} 已涨到 \${quote.current}，超过你的目标价 \${alert.targetPrice}\`;
  }

  if (alert.type === 'below' && quote.current <= alert.targetPrice) {
    return \`📢 【提醒】\${quote.name} 已跌到 \${quote.current}，低于你的目标价 \${alert.targetPrice}\`;
  }
}
