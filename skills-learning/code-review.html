Code Review

全面的代码质量检查，不放过任何问题

🔍 什么是 Code Review

Code Review 是一个全面的代码审查技能。它会从多个角度审查代码：逻辑缺陷、安全漏洞、性能问题、代码风格、API 设计等。

就像请了一个资深工程师来审查代码，但比人工审查更全面、更一致。Code Review 不会疲劳，每次审查标准都保持一致。

📋 审查维度

  • 逻辑缺陷：边界条件、空指针、逻辑错误
  • 安全漏洞：SQL 注入、XSS、敏感信息泄露
  • 性能问题：N+1 查询、内存泄漏、循环优化
  • 代码风格：命名规范、代码结构、可读性
  • API 设计：接口一致性、错误处理、版本兼容
  • 测试覆盖：单元测试、边界测试、覆盖率
🌰 场景示例：PR 审查

开发者提交了一个登录 API 的 PR

Code Review 发现问题：

❌ 安全：密码明文存储（应 hash）

❌ 安全：登录接口无限次数尝试

❌ 逻辑：token 过期未验证

❌ 性能：每次请求都查数据库

⚠️ 风格：函数超过 100 行

⚠️ 测试：边界情况未覆盖

⌨️ 命令格式

基础命令：

code-review "审查 src/api 目录"

审查单个文件：

code-review "审查 auth.ts"

审查 PR：

code-review --pr 123

带严重级别：

code-review --severity "审查安全问题"

🔍 审查类型

  • Style Reviewer：格式、命名、风格规范
  • Code Reviewer：全面代码质量
  • API Reviewer：接口设计、兼容性
  • Security Reviewer：安全漏洞检测
  • Performance Reviewer：性能问题检测
💡 可以组合使用

code-review 默认是全面审查，也可以单独指定某种审查类型。

⚠️ 注意事项

  • 需要代码上下文：最好能访问完整代码
  • 不是银弹：无法发现业务逻辑错误
  • 有优先级：P0 是必须修复的，P3 是建议
  • 需要测试环境：有些问题需要实际运行才能发现
⚠️ 优先修复顺序

P0（安全/致命）→ P1（功能错误）→ P2（性能/可用性）→ P3（代码风格）
