Ultrawork

最大并行度执行，用 Token 换时间

⚡ 什么是 Ultrawork

Ultrawork 是一个并行执行技能，核心理念是"用更多的 Token 换取更短的时间"。当你有多个独立的子任务时，Ultrawork 会同时执行它们，而不是一个一个顺序执行。

就像建筑施工：多台起重机同时工作比一台一台来快得多。Ultrawork 启动多个并行 agent，最大化利用计算资源。

📋 使用场景

  • 多个独立文件修改：同时修改用户、订单、产品三个模块
  • 多文件测试编写：同时为多个模块编写测试
  • 批量重构：同时重构多个相似的文件
  • 并行代码生成：同时生成多个 API 端点
  • 文档批量生成：同时生成多个模块的文档
🌰 场景示例：批量实现 API

用户说："ultrawork 实现用户管理的所有 API"

Ultrawork 同时执行：

• Agent 1: 创建用户 API

• Agent 2: 更新用户 API

• Agent 3: 删除用户 API

• Agent 4: 查询用户 API

• Agent 5: 列表用户 API

原本 5 小时的工作，30 分钟完成

⌨️ 命令格式

基础命令：

ultrawork "实现 src/features 下的所有功能"

指定并行度：

ultrawork --parallel 4 "批量实现 API"

带任务列表：

ultrawork "实现：用户模块、订单模块、支付模块"

⚙️ 工作原理

Ultrawork 采用最大并行执行：

  • 任务分解：把大任务拆成独立子任务
  • 并行调度：启动多个 agent 同时执行
  • 结果汇总：收集所有子任务的结果
  • 冲突处理：处理可能的文件冲突
💡 最大并行度

Ultrawork 默认支持最多 6 个并行 agent。可以通过参数调整，但需要考虑上下文限制。

⚠️ 注意事项

  • 只适合独立任务：有依赖关系的任务不能并行
  • Token 消耗大：多个 agent 并行消耗较多 token
  • 冲突风险：修改同一文件可能导致冲突
  • 上下文限制：过多并行可能导致上下文溢出
⚠️ 不要用 Ultrawork 的场景

单个顺序任务 | 紧密耦合需要共享状态 | Token 预算有限
