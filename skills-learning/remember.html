Remember

持久化项目知识，避免重复踩坑

🧠 什么是 Remember

Remember 是一个知识持久化技能。它的核心理念是"一次踩坑，永不复踩"——把项目中积累的经验和问题解决方案保存下来，供后续使用。

当你发现一个难以解决的问题时，Remember 会帮你把解决方案记录下来。下次遇到同类问题时，AI 会自动查找并应用这些经验。

📋 使用场景

  • 解决复杂 bug 后：把根因和解决方案记录下来
  • 发现代码模式：项目中特定模式的正确用法
  • 踩坑记录：某个第三方库的坑及其绕过方法
  • 最佳实践：团队形成的新规范和约定
  • 环境配置：特定环境下的配置要点
🌰 场景示例：记录数据库坑

发现："MongoDB 在 Docker 中性能很差"

原因："Docker 网络模式导致连接池问题"

解决方案："在 docker-compose 中使用 network_mode: host"

使用 Remember 保存后：

下次配置 MongoDB 时，AI 会自动检查并建议使用 host 模式

⌨️ 命令格式

基础命令：

remember "MongoDB Docker 性能问题"

从对话提取：

remember --learn "提取刚解决的认证问题方案"

查询记忆：

remember --query "数据库"

💾 存储结构

Remember 会把知识保存到：

  • 用户级记忆：~/.claude/skills/omc-learned/
  • 项目级记忆：.omc/skills/
  • 会话记忆：.omc/notepad.md
💡 自动应用

Remember 保存的知识会在相关场景自动触发，不需要每次手动查找。

⚠️ 注意事项

  • 需要具体：记录要具体，不能太泛泛
  • 需要上下文：注明在什么情况下适用
  • 定期整理：记忆会积累，需要定期清理
  • 项目 vs 用户：项目相关的放项目，个人通用的放用户
⚠️ 记录技巧

好的记忆条目包含：问题现象、根因分析、解决方案、适用场景。不要只记"怎么修"，要记"为什么这样修"。
