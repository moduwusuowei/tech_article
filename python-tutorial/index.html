变量：程序的储物箱 📦

变量就像一个有名字的储物箱，你可以在里面放东西，以后再用名字拿出来用。

# 想象变量是一个贴了标签的盒子 # 盒子上写着 "name"，里面放 "小明" name = '小明' age = 18 height = 1.75 print(name) # 输出: 小明 print(age) # 输出: 18 print(height) # 输出: 1.75

✅ 好的变量名

  • user_name — 小写下划线
  • total_count — 见名知意
  • max_value — 驼峰命名

❌ 糟糕的变量名

  • a — 不知道是什么
  • temp123 — 临时变量太多
  • 中文变量 — 别用中文命名
💡 起名小技巧

变量名要像给文件起名一样：简短、清晰、一眼就知道装的是什么！

字符串：文字处理专家 📝

字符串就是一串文字，用引号包起来。单引号、双引号都可以哦！

# 字符串示例 name = 'Python' message = "你好，世界！" empty = '' # 空字符串 print(name) # Python print(len(name)) # 6 - 长度 print(name[0]) # P - 第一个字符 print(name[-1]) # n - 最后一个字符

大小写转换

name = "python" print(name.upper()) # PYTHON print(name.capitalize()) # Python

查找替换

text = "hello world" print(text.replace("world", "Python")) # hello Python

切片操作

text = "Python" print(text[0:3]) # Pyt print(text[::-1]) # nohtyP 逆序

拼接重复

print("Ha" * 3) # HaHaHa print("Hello" + "World") # HelloWorld

列表：有序的数据集合 📋

列表就像一个购物清单，可以装很多东西，而且可以随时添加、删除、修改。

# 创建列表 fruits = ['apple', 'banana', 'orange'] numbers = [1, 2, 3, 4, 5] # 访问元素（从0开始数！） print(fruits[0]) # apple - 第一个 print(fruits[-1]) # orange - 最后一个 print(fruits[0:2]) # ['apple', 'banana'] - 切片

增删改查 CRUD 🔨

➕ 增

fruits.append('grape') # 末尾添加 fruits.insert(1, 'kiwi') # 指定位置添加

➖ 删

fruits.remove('apple') # 删除指定元素 fruits.pop() # 删除最后一个 del fruits[0] # 删除指定位置

🎯 实战：购物车

cart = [] cart.append('iPhone') cart.append('MacBook') cart.append('AirPods') print(cart) # ['iPhone', 'MacBook', 'AirPods'] print(f"共{len(cart)}件商品") # 共3件商品

元组：不可变的列表 🔒

元组和列表很像，但元组一旦创建就不能修改。这是优点——数据更安全！

# 创建元组：用圆括号 dimensions = (1920, 1080) # 屏幕分辨率 point = (100, 200) # 坐标点 # 访问 - 和列表一样 print(dimensions[0]) # 1920 print(dimensions[0:2]) # (1920, 1080)

✅ 元组的优势

  • 数据更安全，不可修改
  • 访问速度更快
  • 可以作为字典的键
  • 用于函数返回多个值

⚠️ 元组的限制

  • 不能添加元素
  • 不能删除元素
  • 不能修改元素
  • 想修改？先转 list！

🎯 实战：函数返回多个值

def get_user_info(): return ("小明", 18, "北京") name, age, city = get_user_info() print(f"{name}今年{age}岁，住在北京") # 小明今年18岁，住在北京

字典：键值对存储 🗂️

字典就像真实的字典，用"键"查找"值"。比列表更快、更直观！

# 创建字典：用花括号，键值用冒号 student = { "name": "小明", "age": 18, "score": 95 } # 访问：通过键找值 print(student["name"]) # 小明 print(student["score"]) # 95

增删改查 🔨

# 增 / 改 student["grade"] = "A" # 添加新键值对 student["age"] = 19 # 修改已有值 # 查 print(student.keys()) # dict_keys(['name', 'age', 'score', 'grade']) print(student.values()) # dict_values(['小明', 19, 95, 'A']) # 删 del student["grade"] # 删除某个键值对 student.clear() # 清空字典

🎯 实战：用户信息管理

users = { "user001": {"name": "张三", "email": "zhang@example.com"}, "user002": {"name": "李四", "email": "li@example.com"} } print(users["user001"]["name"]) # 张三 print(len(users)) # 2

集合 & 布尔：特殊数据类型 🎯

集合：无序去重 🎲

集合自动去重，适合找出共同好友、统计_unique用户等场景。

# 自动去重 tags = {"Python", "Java", "Python", "C++"} print(tags) # {'Python', 'Java', 'C++'} # 集合运算 tags1 = {"A", "B", "C"} tags2 = {"B", "C", "D"} print(tags1 & tags2) # {'B', 'C'} 交集 print(tags1 | tags2) # {'A', 'B', 'C', 'D'} 并集

布尔：真假判断 ✓✗

布尔只有两个值：True（真）和 False（假）。用于条件判断。

# 比较运算 print(10 > 5) # True print(3 == 3) # True - 等于 print(5 != 5) # False - 不等于 print(10 >= 10) # True - 大于等于
💡 记忆技巧

非空字符串、非零数字、非空列表 → True
空字符串、0、空列表 → False

🎯 实战：用户登录验证

is_logged_in = True is_admin = False # 判断权限 if is_logged_in and is_admin: print("管理员可访问后台") elif is_logged_in: print("普通用户可访问前台") else: print("请先登录")

循环：让重复变得简单 🔄

while 循环就像游戏里的"再来一局"，满足条件就一直执行，直到条件不满足为止。

while 循环

# 打印 1 到 5 count = 1 while count <= 5: print(count) count += 1 # 别忘了改变条件，否则会无限循环！ # 输出: 1 2 3 4 5

while...else（循环的保险箱）

count = 0 while count < 3: print(f"第{count+1}次") count += 1 else: print("循环正常结束") # 循环没被break时执行
⚠️ 避免死循环

确保循环条件最终会变成 False，或者使用 break 主动退出，否则程序会卡死！

🎯 实战：猜数字游戏

import random target = random.randint(1, 10) attempts = 0 while attempts < 3: guess = int(input("猜一个1-10的数字：")) attempts += 1 if guess == target: print(f"恭喜！猜对了！用了{attempts}次") break elif guess < target: print("太小了，往大猜") else: print("太大了，往小猜")

for 循环：遍历专家 🔍

for 循环专门用来"遍历"——依次访问列表、字符串、字典中的每个元素。

遍历字符串

for letter in "Python": print(letter, end=" ") # P y t h o n

遍历列表

fruits = ["苹果", "香蕉", "橙子"] for fruit in fruits: print(fruit) # 苹果 # 香蕉 # 橙子

range() 生成数字序列

for i in range(5): # 0,1,2,3,4 print(i) for i in range(1, 6): # 1,2,3,4,5 print(i) for i in range(0, 10, 2): # 0,2,4,6,8 步长2 print(i)

🎯 实战：计算总和

numbers = [1, 2, 3, 4, 5] total = 0 for n in numbers: total += n print(f"总和是：{total}") # 15 print(f"平均值是：{total/len(numbers)}") # 3.0

循环控制：break & continue 🛑

break：直接退出循环

for i in range(1, 10): if i == 5: break # 遇到5就停止 print(i) # 输出: 1 2 3 4

continue：跳过本次循环

for i in range(1, 6): if i == 3: continue # 跳过3，继续下一个 print(i) # 输出: 1 2 4 5
💡 记忆技巧

break = 踩刹车，停车（退出循环）
continue = 继续走，跳过当前站（进入下一次循环）

🎯 实战：筛选合格商品

products = [95, 45, 88, 60, 72, 30] qualified = [] for score in products: if score < 60: continue # 不及格，跳过 qualified.append(score) print(qualified) # [95, 88, 60, 72] print(f"合格率：{len(qualified)/len(products)*100:.1f}%") # 66.7%

文件读写模式 📂

'r' 读模式

读取文件内容，文件不存在会报错

'w' 写模式

写入文件，会清空原有内容

'a' 追加模式

在文件末尾添加新内容

'x' 创建模式

创建新文件，已存在会报错

# 写入文件 with open("hello.txt", "w") as f: f.write("Hello Python!\n") f.write("Python真好玩") # 读取文件 with open("hello.txt", "r") as f: content = f.read() print(content)
💡 推荐：用 with 自动管理资源

with 语句会在代码块结束时自动关闭文件，即使出错了也能保证文件被正确关闭！

🎯 实战：日志记录器

with open("access.log", "a") as log: log.write(f"2024-01-15 用户小明访问了系统\n") log.write(f"2024-01-15 用户小红登录了系统\n") # 查看日志 with open("access.log", "r") as f: for line in f: print(line.strip())
