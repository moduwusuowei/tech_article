# claude_demo

## Purpose
静态个人网站项目，采用现代卡片式布局风格，用于展示个人信息、作品集和联系方式。

## Key Files
| File | Description |
|------|-------------|
| `index.html` | 主页，展示个人信息 |
| `about.html` | 关于页面 |
| `projects.html` | 项目作品展示 |
| `src/css/style.css` | 主样式文件 |
| `src/js/main.js` | 交互逻辑 |

## Subdirectories
| Directory | Purpose |
|-----------|---------|
| `src/` | 源代码目录 |
| `src/css/` | 样式文件 |
| `src/js/` | JavaScript 文件 |
| `assets/` | 静态资源（图片等） |

## For AI Agents

### 技术栈
- 纯 HTML/CSS/JS，无框架依赖
- 响应式设计，支持移动端
- CSS Grid + Flexbox 布局

### 开发命令
- 使用任意静态服务器预览：`python -m http.server 8000 --bind 0.0.0.0`

### 添加新页面
1. 复制现有 HTML 模板
2. 更新导航链接
3. 修改页面内容

## Dependencies

### External
- Google Fonts: Inter (可选)
- 无其他外部依赖
