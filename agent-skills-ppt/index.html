    Skills 能力对比与选型指南

    Skill 核心能力 适用任务 复杂度 效率提升
    Ralph 循环执行 + 自我修复 Bug 修复、重构优化 中 10-15x
    Autopilot 全自动化流水线 完整功能开发 高 5-8x
    Team 多 Agent 并行 复杂系统开发 高 3-5x
    Plan 需求分析 + 规划 架构设计、需求确认 中 3x
    Code Review 代码质量检查 代码审查、安全扫描 低 15x

    Ultraqa 测试 → 验证 → 修复循环 质量保证 中 8x
    Verify 完成度验证 交付确认 低 2x

    选型建议：简单任务用单个 Skill，复杂任务用 Skill 组合。例如：完整功能开发 = Plan (规划) + Autopilot (执行) + Code Review (审查) + Verify (验证)
